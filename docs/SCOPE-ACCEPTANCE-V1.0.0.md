# YIMING STUDIO 1.0.0 — 全量范围与验收矩阵

## 产品原则

- 中国市场优先，中文内容。
- 品牌方向：智能未来生活；视觉基调：科技未来主义与建筑空间感。
- 核心口号：先确认能不能装，再决定值不值得选。
- 公开只读知识库，不做商城、登录、支付、留资或真实设备控制。
- 产品、图片、3D、光学和工程信息必须真实可核验；概念图必须明确标注“示意”。

## 产品数据准入规则

1. 官方目录可证明产品名称与品类，不自动证明完整规格或当前库存。
2. 官方规格页用于确认参数和准确型号。
3. 官方兼容页用于确认特定功能、主机、固件或生态路径。
4. 开源社区数据库只能作为交叉核验，不可冒充厂商官方支持。
5. 实测必须有设备、硬件版本、固件版本、环境、步骤、结果和日期。
6. 所有参数字段必须关联来源；未知值留空。
7. 图片与 3D 必须通过版权和准确型号核验。
8. 静态价格不进入产品固有规格。

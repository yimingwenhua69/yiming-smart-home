# Asset Truth and Freshness Policy

Status: mandatory release policy  
Effective: 2026-11-26

## Non-negotiable rule

All product, scene, installation, engineering and technical images displayed by YIMING SMART HOME must be genuine, traceable and current for the stated product/model/region. This rule outranks visual completeness, page density and delivery speed.

## Product imagery

- Must depict the exact product and variant/model being described.
- Prefer current official manufacturer imagery or explicitly licensed imagery.
- Record source URL, publisher, productModelId, capturedAt when known, verifiedAt, region, revision and license/permission.
- Do not use an image of a visually similar model as a substitute.
- Do not use an old generation image for a current generation product.
- Do not infer image currency from upload date or a page still being online.
- If image rights are unclear, link to the official product page and do not re-host the image.

## Scene imagery

- Real project photography must have a traceable source and permission status.
- Manufacturer case-study images must be attributed and used only within permitted terms.
- AI-generated scenes, concept renders and synthetic composites must never be represented as real completed projects.
- If a scene is a concept or simulation, label it explicitly and keep it out of the real-case gallery.

## Technical and installation imagery

- Must correspond to the actual device, wiring topology, hardware revision and installation method.
- Safety-critical electrical diagrams require official documentation or qualified engineering review.
- Do not reproduce an installation diagram by guessing from product appearance.

## 3D assets

- Allowed provenance: official CAD/model, actual scan, or reconstruction from verified physical measurements and multi-angle references.
- Record provenance and exact model linkage.
- Reconstructed models must be labeled as reconstructed, not official.
- No unverified generic mesh may be presented as a real product.
- If model accuracy cannot be established, omit the 3D model.
- IES/LDT files and photometric profiles must be tied to the exact luminaire/model and source.

## Asset lifecycle

Statuses:
- current
- needs-review
- superseded
- withdrawn
- rights-unverified

Recheck assets when the manufacturer updates the product page, a model/variant changes, an asset source disappears, permission changes or a new revision is released. Superseded or rights-unverified assets must not appear as current assets.

## Fallback

When there is no verified and usable image, show the product name, model and official source link without an image. Do not generate a fake replacement.
